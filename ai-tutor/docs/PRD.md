# AI 私教系统 — 产品需求文档 (PRD)

> 版本：1.0 | 最后更新：2026-09-04

---

## 1. 产品概述

### 1.1 产品定位

AI 私教系统是一款面向编程学习者的智能教学平台，结合 RAG（检索增强生成）、费曼学习法和间隔重复算法，为每位学习者提供个性化的编程知识学习路径。

### 1.2 产品愿景

让每位编程学习者都拥有一位 24 小时在线的专属 AI 教师，通过科学的学习方法帮助用户高效掌握编程知识。

### 1.3 核心价值主张

| 传统学习 | AI 私教 |
|---------|--------|
| 被动阅读文档 | 主动测验 + 费曼输出 |
| 遗忘曲线无管理 | SM-2 间隔重复自动安排复习 |
| 知识碎片化 | RAG 关联知识检索，形成知识网络 |
| 无法评估掌握度 | 多维度掌握度追踪 |

---

## 2. 目标用户

### 2.1 主要用户画像

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| 编程初学者 | 刚入门编程，需要系统化学习 | 理解概念、建立知识体系 |
| 在职开发者 | 想学习新技术栈（如 Rust、Go） | 高效吸收新知识、避免遗忘 |
| 面试准备者 | 需要快速掌握特定领域知识 | 针对性测验、错题强化 |
| 自学者 | 缺乏导师指导 | 费曼学习法自我检验 |

### 2.2 用户规模预期

- 初期：100-500 用户（内测）
- 中期：1,000-10,000 用户
- 远期：10,000+ 用户

## 3. 核心功能详述

### 3.1 用户系统

#### 用户故事

> 作为编程学习者，我想要通过邮箱快速注册和登录，以便安全地管理我的学习数据。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 邮箱注册 | 输入邮箱、用户名、密码完成注册 |
| 登录 | 邮箱 + 密码登录，获取 JWT Token |
| Token 认证 | 所有 API 请求携带 Bearer Token |
| 自动登录 | Token 有效期内免重复登录 |

#### 验收标准

- [ ] 注册时邮箱格式校验，重复邮箱提示错误
- [ ] 密码最少 6 位，包含字母和数字
- [ ] 登录成功后跳转至仪表盘
- [ ] Token 过期后自动跳转登录页
- [ ] 用户名显示在侧边栏

---

### 3.2 文档管理

#### 用户故事

> 作为学习者，我想要导入编程文档（URL 或文件），系统自动处理并建立知识库，以便后续测验和复习。

#### 功能清单

| 功能 | 描述 |
|------|------|
| URL 导入 | 输入文档 URL，系统自动抓取内容 |
| 文件上传 | 支持 PDF、Markdown、TXT 文件上传 |
| 标签系统 | 为文档添加标签，便于分类管理 |
| 重复检测 | 导入重复文档时弹窗提示用户选择 |
| 重复处理 | 用户可选择「放弃导入」或「重新导入」 |
| 重新导入 | 逻辑删除旧文档，导入新内容 |
| 文档列表 | 展示所有文档，含状态、标签、块数 |
| 文档删除 | 逻辑删除文档（不物理删除） |

#### 重复检测流程

```
用户输入 URL → 系统检测是否已存在
  ├─ 不存在 → 正常导入
  └─ 已存在 → 弹窗提示
       ├─ 放弃导入 → 取消操作
       └─ 重新导入 → 旧文档逻辑删除 → 新文档入库
```

#### 验收标准

- [ ] URL 导入后状态显示「处理中」，完成后显示「已完成」
- [ ] 重复 URL 导入时弹窗显示已有文档标题
- [ ] 「重新导入」后旧文档被逻辑删除，新文档正常入库
- [ ] 标签支持逗号分隔输入，文档卡片上显示标签
- [ ] 删除文档需二次确认
- [ ] 文档列表按创建时间倒序排列

---

### 3.3 RAG 知识检索

#### 用户故事

> 作为学习者，我想要系统基于我导入的知识库回答问题，以便获得准确且有依据的学习内容。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 文档切分 | 自动将文档切分为知识块 |
| 向量化 | 使用 Embedding 模型将知识块转为向量 |
| 语义搜索 | 基于向量相似度检索相关知识块 |
| 查询重写 | AI 优化用户查询，提高检索准确性 |
| 上下文注入 | 将检索结果作为上下文注入 AI 对话 |

#### 验收标准

- [ ] 文档导入后自动切分并生成向量
- [ ] 搜索结果按相关度排序
- [ ] 查询重写后检索结果更精准
- [ ] 未导入文档时搜索返回空结果

---

### 3.4 智能测验

#### 用户故事

> 作为学习者，我想要基于已学知识自动生成测验题，以便检验自己的掌握程度。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 题目生成 | 基于知识库自动生成选择题、简答题、概念分析题 |
| 提交批改 | AI 自动批改并给出评分和反馈 |
| 错题本 | 记录所有答错的题目 |
| 掌握度追踪 | 根据答题结果更新知识点掌握度 |
| 错题重练 | 可选择错题进行重新练习 |

#### 题目类型

| 类型 | 描述 | 评分方式 |
|------|------|---------|
| 选择题 | 四选一，考查概念理解 | 正确/错误 |
| 简答题 | 开放式回答，考查理解深度 | AI 评分 0-100 |
| 概念分析题 | 分析代码或概念，考查综合能力 | AI 评分 0-100 |

#### 验收标准

- [ ] 点击「生成测验」后 10 秒内出题
- [ ] 题目基于导入的知识库内容
- [ ] 提交后即时显示评分和详细反馈
- [ ] 错题自动进入错题本
- [ ] 掌握度根据答题正确率动态调整

---

### 3.5 费曼学习法

#### 用户故事

> 作为学习者，我想要用自己的话解释编程概念，让 AI 评估我的理解程度，以便发现知识盲区。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 开始会话 | 选择一个知识主题开始费曼学习 |
| 用户解释 | 用户用自己的话描述概念 |
| AI 评分 | AI 评估解释的准确性和完整性 |
| 知识补充 | AI 指出遗漏或错误的部分 |
| 加入复习 | 将薄弱知识点加入复习计划 |

#### 费曼学习流程

```
选择主题 → 用户用自己的话解释 → AI 评分
  ├─ 理解良好（≥80分）→ 鼓励 + 加入复习
  └─ 理解不足（<80分）→ AI 补充讲解 → 建议重新学习
```

#### 验收标准

- [ ] 支持多轮对话式解释
- [ ] AI 评分包含准确性和完整性两个维度
- [ ] 评分后给出具体的改进建议
- [ ] 可一键将薄弱点加入复习计划

---

### 3.6 间隔复习

#### 用户故事

> 作为学习者，我想要系统自动安排复习计划，以便在遗忘前及时巩固知识。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 复习计划 | 基于 SM-2 算法自动生成复习计划 |
| 待复习列表 | 展示今日待复习的知识点 |
| 复习提交 | 完成复习后提交反馈 |
| 掌握度更新 | 根据复习表现更新掌握度和间隔 |
| 复习统计 | 展示复习完成率和掌握度变化 |

#### SM-2 算法参数

| 参数 | 描述 |
|------|------|
| 间隔天数 | 下次复习的天数间隔 |
| 重复次数 | 已复习的次数 |
| 易度因子 | 调整复习间隔的系数（1.3-2.5） |
| 掌握度 | 0-100 的掌握程度评分 |

#### 复习反馈选项

| 反应 | 效果 |
|------|------|
| 忘记了 | 间隔重置，掌握度下降 |
| 困难 | 间隔缩短，掌握度微降 |
| 良好 | 间隔适当增加，掌握度上升 |
| 容易 | 间隔大幅增加，掌握度上升 |

#### 验收标准

- [ ] 每日自动计算待复习知识点
- [ ] 复习完成后即时更新掌握度和下次复习时间
- [ ] 忘记的题目间隔重置为 1 天
- [ ] 复习统计展示 7 天趋势

### 3.7 学习进度

#### 用户故事

> 作为学习者，我想要直观看到自己的学习进度和掌握情况，以便调整学习计划。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 仪表盘 | 展示总文档数、总知识点、已掌握数、平均掌握度 |
| 今日学习 | 文档阅读、完成测验、费曼对话、复习完成数 |
| 7天趋势 | 近 7 天学习得分趋势图 |
| 掌握度分析 | 各知识点掌握度分布 |

#### 验收标准

- [ ] 仪表盘数据实时更新
- [ ] 7 天趋势图正确展示每日得分
- [ ] 掌握度分布用颜色区分（已掌握/学习中/未学习）

### 3.8 AI 对话

#### 用户故事

> 作为学习者，我想要与 AI 进行多轮对话，随时提问编程问题，以便获得即时解答。

#### 功能清单

| 功能 | 描述 |
|------|------|
| 多轮对话 | 支持上下文关联的多轮问答 |
| 流式输出 | SSE 实时流式返回 AI 回复 |
| 知识关联 | 对话时自动检索相关知识库内容 |
| 会话管理 | 创建、查看、删除对话会话 |

#### 验收标准

- [ ] AI 回复支持流式输出，逐字显示
- [ ] 对话自动关联知识库内容
- [ ] 历史对话可回溯查看
- [ ] 支持创建新会话

## 5. 非功能需求

### 5.1 性能

| 指标 | 目标 |
|------|------|
| 页面加载 | ≤ 2 秒 |
| API 响应 | ≤ 500 ms（非 LLM 接口） |
| LLM 响应 | 首 token ≤ 3 秒，流式输出 |
| 文档导入 | 单文档 ≤ 60 秒 |
| 并发用户 | 支持 100 并发 |

### 5.2 可用性

- 系统可用性 ≥ 99.5%
- 数据备份每日执行
- 故障恢复时间 ≤ 30 分钟

### 5.3 安全性

- 密码 bcrypt 加密存储
- JWT Token 有效期 24 小时
- API 请求全部需要认证
- 用户数据隔离（只能访问自己的数据）

### 5.4 兼容性

- 浏览器：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- 分辨率：支持 1280px 及以上

## 6. 产品成功指标 (KPI)

| 指标 | 目标 | 衡量方式 |
|------|------|---------|
| 用户注册转化率 | ≥ 60% | 访问注册页 → 完成注册 |
| 文档导入成功率 | ≥ 90% | 导入完成 / 导入请求 |
| 测验完成率 | ≥ 70% | 开始测验 → 完成提交 |
| 复习执行率 | ≥ 50% | 完成复习 / 待复习数 |
| 平均掌握度提升 | ≥ 20% | 使用 7 天后掌握度变化 |
| 用户次日留存 | ≥ 40% | 次日活跃 / 首日注册 |
| 用户 7 日留存 | ≥ 25% | 7 日活跃 / 首日注册 |
